## What I Learned

- The most challenging part was troubleshooting SSH connectivity and public key authentication between Windows Server, Ubuntu Linux, and pfSense.
- I worked through the issues by reviewing configuration files, verifying SSH service status, checking firewall rules, and validating network connectivity.
- Next time, I would verify connectivity and routing earlier in the project to reduce troubleshooting time.
